# led-breakout-board
A simple 3-channel LED breakout board designed in KiCad for easy connection and control of LEDs with a microcontroller.

## 🔧 Features

- 3 independent LED channels
- Individual current-limiting resistors
- Common GND
- Header connector for easy connection
- Designed for use with microcontrollers

## 🛠️ Tools Used

- KiCad
- PCB Design
- Schematic Design
